# Lakshana's Personal Portfolio

A personal portfolio website showcasing my skills, projects, education, and professional journey as a Computer Science graduate and aspiring software developer.

## About

This portfolio is designed to present my technical skills, projects, and career profile in a clean and responsive interface. It highlights my interests in software development, web development, and front-end development.

## Built With

- HTML5
- Tailwind CSS
- JavaScript
- Git
- GitHub

## Features

- Clean and modern UI
- Responsive design
- Burgundy, rose and white color theme
- About Me section
- Technical Skills section
- Projects showcase
- Resume section
- Contact section

## Project Structure

```text
Personal-Portfolio-Website/
│
├── index.html
└── README.md
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/lakshana1435/Personal-Portfolio-Website.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser to view the portfolio.
